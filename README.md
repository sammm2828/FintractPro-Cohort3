# 🚀 FinTrack Pro - Personal Finance & Expense Tracker

> A modern, responsive, and feature-rich personal finance management web application designed to help you track income, expenses, and overall cash flow effortlessly.

---

## 🔗 Live Demo
Check out the live deployment of the project here:  
👉 **[FinTrack Pro Live](https://fintract-pro-cohort3.vercel.app/)**

---

## ✨ Features

- **Dashboard Overview:** Real-time calculation of Current Balance, Total Income, Total Expense, and Transaction Count.
- **Visual Analytics:** Interactive Bar Charts powered by Chart.js to monitor daily/monthly cash flows.
- **Transaction Filtering:** Easily filter transactions by **All Types**, **Income Only**, or **Expense Only**[cite: 1, 2].
- **Local Storage Support:** Data persistence ensures your transactions, dark mode preferences, and currency settings stay saved even after a page refresh.
- **Multi-Currency Support:** Convert and display values dynamically in INR (₹), USD ($), EUR (€), GBP (£), and AED (د.إ).
- **Authentication & Profiles:** Minimalist Login & Sign-up screens with real-time profile name and initial customization (e.g., "SP" for Soham Parmar).
- **Dark Mode / Light Mode:** Seamless theme switching with persistent storage.
- **Fully Responsive:** Optimized layout for both Desktop and Mobile devices.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic and structured markup.
- **CSS3:** Custom styling with CSS Variables, Flexbox, CSS Grid, and Media Queries.
- **JavaScript (ES6+):** DOM manipulation, local storage handling, and event management.
- **Libraries & Icons:** 
  - [Chart.js](https://www.chart.js/) (for data visualization)
  - [RemixIcon](https://remixicon.com/) (for clean vector UI icons)
